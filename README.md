## FAQ

### Is this tool safe to use?

XCutors itself is a loader and manager for other tools. We recommend scanning all files with anticomponent software. Usage of any executor is at your own risk.

### Does it work on macOS or Linux?

No. XCutors is designed and packaged specifically for Windows desktop operating systems.

### Are the bundled executors (Volt, Synapse Z) included legally?

This repository hosts the loader and documentation. You must acquire and place the executor binaries yourself if required, adhering to their respective terms of service.

### How do I update the executors?

The xcutorsLoader can check for updates. For individual executor updates, refer to their official channels and replace the corresponding files in the tools directory.

### My anticomponent flags the program as a threat. Is this normal?

Some security software may issue false positives for tools that interact with other processes. We recommend adding an exception, but only if you trust the source.

### Can I add other executors to the collection?

Yes. Advanced users can modify the loader's configuration to include additional executor paths, though support varies.

### What happens if Roblox updates and a script fails?

Script functionality depends on the executor's internal offsets. Update the executor to the latest version from its developer for continued compatibility.

### Is there support for mobile or console versions?

No. XCutors is exclusively for the Windows desktop version of Roblox.

### Do I need to disable my anticomponent to run this?

It may be required for some anticomponent suites. However, you should only do this for software from sources you completely trust.
